# 1. Grill summary (requirements handshake)
Source: PRD "Lesin — Marketplace Tutor" (27 Nov 2026, tutor-pays model). Items marked **ASSUMED** need the founder's confirmation.

| Question | Answer |
|---|---|
| What is it? | PWA marketplace: parents find a private tutor near home. Parents free; tutors pay Rp15,000/lead or Rp99,000/month (8 leads). No tuition commission. |
| Who are the users? | **Parent** (30–45, Jakarta Selatan, phone-first, busy, wary of strangers entering the home). **Tutor** (student, fresh grad, teacher; wants students; price-sensitive). **Admin** (founder). |
| Primary parent task | Find 1–3 suitable tutors → send one free request → talk on WhatsApp. |
| Primary tutor task | See requests in my area → spend 1 lead → open WhatsApp. Buy leads when empty. |
| Retention loop | Lesson hub: weekly slot, WhatsApp reminder, tutor session note. |
| Devices | Mobile first (PWA). Desktop secondary. ASSUMED: 360–414 px is the design target. |
| Language | Bahasa Indonesia, informal-polite ("Anda"). |
| Trust constraints | Name, photo, WhatsApp hidden until unlock (server-enforced). Verified badge. First trial attended by a parent. |
| Scale (pilot) | 2 districts, ~100 tutors, ~250 requests in 6 months. Low traffic; clarity beats density. |
| Edge cases | No tutors for filter; request full (10 tutors); no leads left; payment pending/expired/failed; request expired (14 days); tutor unverified. |
| Out of scope | In-app chat, tuition payment, group classes, native apps. |
| Success | Parents finish a request unaided (8/10). 3 of 5 tutors would pay Rp15,000. Parents return in 60 days (25%). |
| Feel | ASSUMED: calm, trustworthy, local, plain. Not playful, not corporate-cold. References: Tokopedia-style clarity, Linear-style restraint. |
